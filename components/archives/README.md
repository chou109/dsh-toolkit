# archives (retired)

This component is **retired** and is not installed by `install.ps1`/`install.sh`.

DSH 0.2 ships native archived-session support: archive/unarchive in the Session
row menu, “All conversations / Archived only” view filtering, archived result
handling in search, and live updates. See the standalone
[dsh-archives](https://github.com/chou109/dsh-archives) repository for the full
retirement note.

The code here is the 0.1.x implementation, kept as a historical reference only.
It must not be loaded on 0.2.x.
